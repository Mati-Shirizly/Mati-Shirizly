## Features

The Markdown Viewer includes the following features:

- **File Upload**: Choose or drag & drop markdown files
- **Theme Support**: Switch between light, dark, and system themes
- **PDF Export**: Save your rendered markdown as a PDF
- **Print Support**: Print directly from the browser

And here's some Python code:

```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))
```
